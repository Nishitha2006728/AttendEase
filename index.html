About AttendEase

Application
AttendEase
Tagline
Smart and Simple Student Attendance Management.
Version
1.0.0
Description
A browser-based attendance system for colleges. It lets staff manage students, record daily attendance (Present / Absent / Late), and view percentage reports with a low-attendance warning and CSV export. All data is stored locally in the browser using LocalStorage, so no server is needed.
Technology stack
